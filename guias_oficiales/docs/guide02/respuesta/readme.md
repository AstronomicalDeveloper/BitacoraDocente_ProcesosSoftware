## Respuesta a la pregunta de investigación

No, el modelo de ciclo de vida en espiral no es aplicable para terminar este proyecto debido a la sobrecarga administrativa que conlleva.

## Explicacion
Con solo tres meses restantes, dedicar tiempo a las fases intensivas de planificación y análisis de riesgo de cada vuelta de la espiral restaría tiempo valioso a la programación e integración real que falte implementar.

La metodología Sashimi que ya escogimos llegó a ser mucho más eficiente, a pesar de encontrarnos con graves obstaculos en la etapa final, con una mayor integración del equipo y un mejor uso de herramientas más flexibles para el desrrollo del proyecto, se nos hubiera permitido solapar la conexion de la API con la interfaz de usuario sin detener el desarrollo por distintos errores o atrasos que se presentaron en la recta final.
