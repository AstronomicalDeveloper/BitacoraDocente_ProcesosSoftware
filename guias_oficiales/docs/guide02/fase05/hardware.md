## Hardware

En esta sección se detalla el hardware empleado para desarrollar el prototipo durante todas las fases del ciclo de vida del software.

---

###  Equipos utilizados por el equipo de desarrollo

#### 💻 Equipo de Trabajo Principal
- **Tipo:** Laptop / PC de desarrollo
- **Procesador:** Intel Core i5 / Ryzen 5 (o superior)
- **Memoria RAM:** 8 GB (recomendado 16 GB para ejecución simultánea de herramientas)
- **Almacenamiento:** 256 GB SSD (mínimo), con soporte para lectura/escritura rápida
- **Tarjeta gráfica:** Integrada (suficiente para entornos de desarrollo)
- **Sistema Operativo:** Windows 10 / Windows 11
- **Monitor:** 14–24” resolución HD o superior
- **Periféricos:**
  - Teclado de notebook o externo
  - Mouse óptico o inalámbrico
  - Auriculares para reuniones virtuales (opcional)

---

###  Conectividad Requerida
- **Internet estable** (mínimo 10 Mbps) para:
  - Acceso a GitHub
  - Uso de herramientas online (Canva, Lucidchart)
  - Instalación de dependencias npm
  - Actualizaciones del entorno
