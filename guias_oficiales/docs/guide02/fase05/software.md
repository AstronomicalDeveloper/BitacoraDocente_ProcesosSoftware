##  FASE 04: Implementación del Prototipo

###  Software utilizado

####  Visual Studio Code
- **Uso:** Desarrollo y edición del código fuente.
- **Características técnicas:**
  - Terminal integrada
  - Extensiones React/TypeScript
  - Integración con Git

####  Lenguaje de Desarrollo
- **Tecnología:**  TypeScript
- **Framework:** React
- **Características técnicas:**
  - SPA (Single Page Application)
  - Arquitectura basada en componentes
  - Virtual DOM

####  Librerías utilizadas
| Librería | Rol Técnico | Características |
|---------|-------------|-----------------|
| **React Router** | Navegación SPA | Rutas dinámicas sin recarga |
| **React Query** | Gestión de datos | Caché, sincronización, revalidación automática |
| **Axios** | Cliente HTTP | Manejo de promesas y headers REST |

####  MariaDB
- **Uso:** Base de datos relacional del sistema.
- **Características técnicas:**
  - SQL
  - Integridad referencial
  - Compatibilidad con MySQL

####  DBeaver
- **Uso:** Administración visual de la base de datos.
- **Características técnicas:**
  - Cliente multi-SGBD
  - Editor SQL
  - Inspección de datos
